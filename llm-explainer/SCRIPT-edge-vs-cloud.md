## 口播全文

### 1. 引出
嗨，我是呱基。地铁没信号、飞机上、断网办公——没网了，AI 还能跑吗？答案是：看你用的是哪种 AI。

### 2. 两种 AI
常见有两种：端侧模型，装在你手机或电脑里；云端模型，跑在远程的算力中心。一个在身边，一个在远方。

### 3. 端侧怎么跑
端侧，就是把模型文件下载、部署到设备上。推理靠本机芯片的算力——CPU、GPU、NPU。算力在你口袋里，所以可以不依赖网络。

### 4. 云端怎么跑
云端呢？你的问题通过网络，送到机房里的大服务器。真正费算力的活，在远程算力中心完成，再把答案传回来。没网，这条路就断了。

### 5. 端侧优劣
端侧好处：能离线、数据更不容易离开本机、本地响应往往更快。代价是：模型通常更小、能力有限，还占存储、比较费电。

### 6. 云端优劣
云端好处：模型往往更大更强，功能更新也快。代价是：必须联网；内容会经过远端；高峰时还可能排队变慢。

### 7. 怎么选 + 收尾
怎么选？要离线、要隐私、要随手秒回——优先端侧。要复杂推理、长文创作、最新能力——用云端。很多 App 其实两边都会用。我是呱基，我们下期见。

## 类比备忘

| 概念 | 类比 |
|------|------|
| 端侧 | 家里小厨房：随时能开火，但灶台小 |
| 云端 | 中央厨房外卖：菜更丰盛，但要有路（网络） |
| 芯片算力 | 厨房炉火大小，决定炒得动多大份量 |
| 算力中心 | 远处的大型中央厨房集群 |

## 干货清单

- [ ] 没网场景：优先看设备是否带端侧模型  
- [ ] 隐私敏感：能本地完成的，先本地  
- [ ] 重活/最新能力：上云端  
- [ ] 日常轻聊：端侧或轻量模型更省  
- [ ] 很多产品是「端云协同」，不是二选一
