## 口播全文

### 1. 引出
嗨，我是呱基。很多人觉得大模型只会聊天、写文章。其实按「能接收什么、能产出什么」，本领远不止文字。

### 2. 按模态分
先记三个名字：LLM 大语言模型，主要和文字打交道；VLM 视觉语言模型，还能看图、看屏幕；Omni 全能模型，往听和说再迈一步，多模态进出更完整。

### 3. LLM
LLM：输入主要是文字，输出也是文字。适合问答、写作、翻译、改稿、写代码、整理会议纪要。像一位超级文字助手。

### 4. VLM
VLM：输入可以是图片、文档截图，再加你的文字问题；输出多是文字解释。比如识图答题、读表读票、看设计稿提意见、拍白板帮你整理要点。

### 5. Omni
Omni：目标是听、说、看、写更打通。你可以语音提问，它口头回答；也能边看画面边解说。适合免打字对话、口语练习、现场讲解。

### 6. 怎么选
怎么选？纯文字任务用 LLM 就够。要理解图片、截图、扫描件，找 VLM。想语音连聊、少动手，再看 Omni。名字不重要，先看输入输出够不够用。

### 7. 收尾
一句话：LLM 主攻文字，VLM 加上眼睛，Omni 往耳朵嘴巴再扩展。按场景选技能，比死记缩写更有用。我是呱基，我们下期见。

| VLM | 带眼睛的助手 |
| Omni | 能看能听能说的全能助手 |

## 场景速查

- LLM：写信、翻译、改简历、写脚本、写代码注释  
- VLM：拍题讲解、识别菜单、读合同截图、看 UI 提建议  
- Omni：开车/做饭时语音问答、口语陪练、看视频口头总结
