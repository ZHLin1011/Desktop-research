# 第 10 期 · 模型的推理服务（按下发送之后）

- 页面：`model-serving.html`（白底，1080×1920，约 246 秒）
- 主线：一次提问要走「五站」——入口 → 调度 → 读题（预填充）→ 写答案（解码）→ 流式送回。中途三个比喻：读题 / 写答案、小本本（KV 缓存）、公交车拼车（连续批处理）。
- 颜色分工：入口 / 网络蓝，调度青，模型 / 读题紫，GPU / 写答案绿，缓存 / 批量 / 价格暖橙，故障 / 浪费红。
- 与第 9 期的分工：第 9 期讲「整个后厨」，本期只拆「推理服务」这一条线；第 9 期一笔带过的拼锅、备菜，本期展开成连续批处理和 KV 缓存。

## 分镜与旁白

| 场景 | 画面 | 要点 |
|---|---|---|
| 01 按下发送之后 | 后厨里点亮「推理服务」→ 训练 / 推理两张卡 → 累计花费曲线（训练一次性，推理一直涨）→ 手机、秒表、五站路线图 | 推理 = 训练好的模型回答你；很多公司账单里推理是长期大头；按下发送到首字只要 1–2 秒，要走五站 |
| 02 入口和调度 | 手机 → 入口三项检查（身份、额度、人多不多）；调度挑中「装好模型 · 不太满」的机器；限流红点、「服务繁忙」 | 先排队，再挑机器；高峰限流 |
| 03 先读题，再写答案 | 11 个字同时亮起（并排读完）；10 个字逐个冒出（一个接一个）；「首字看排队 + 读题，字速看写答案」；字推到屏幕 | 预填充并行、解码串行；流式输出 |
| 04 小本本：KV 缓存 | 第 100 个字回看 99 个字 → 小本本；显存条里本本变厚、能服务的人从 8 降到 3；整本预留空着 vs 一页一页发 | KV 缓存省重算但占显存；分页管理多服务 2–4 倍 |
| 05 公交车式拼车 | 单人公交 → 包车（等最慢的，写完干等）→ 公交（谁写完谁下车、立刻补人）→ 车上人数增加，成本降、等待升 | 连续批处理 |
| 06 快、多、省，选不全 | 人少 / 人多两张对照卡 → 实时通道 vs 批量通道（约 5 折）→ 装模型要几分钟，提前加机器 | 档位取舍；扩容有冷启动 |
| 07 怎么用得更快更省 | 四行小办法：说清楚别啰嗦；换话题开新对话；固定说明放最前；不急的活选批量 | 用户价值落点 |
| 08 一次提问，走五站 | 五站路线图逐站亮起；小本本 / 公交式拼车 / 档位三行对照；「这一秒里，它已经走完了一整趟旅程」 | 收束 |

完整逐句旁白在 `model-serving.html` 的 `SCENES` 中（TTS 逐词时间戳生成，画面按节拍对齐）。

## 数字依据

| 画面 / 旁白 | 依据 | 备注 |
|---|---|---|
| 推理是长期大头 | 行业常见说法：模型上线后，推理的累计算力成本会超过一次性的训练，云厂商公开材料给过「推理占机器学习基础设施成本六到九成」一类的量级 | 不同公司差异大，旁白只说「很多公司账单里是大头」，图为示意 |
| 首字 1–2 秒、字速每秒几十个字 | 主流对话产品常见：首字延迟约 0.5–2 秒，输出约 30–100 token/s；中文阅读约 5–8 字/秒 | 量级，因模型和负载而异 |
| 读题并行、写答案串行 | 预填充（prefill）一次处理整段输入；解码（decode）自回归，每步一个 token，并要读取全部权重 | 标准术语：TTFT（首 token 延迟）与每 token 间隔 |
| 8000 字长对话约 2–3 GB 小本本 | 估算：70B 级模型（80 层、8 个 KV 头、头维度 128、16 位）每 token 的 KV 约 2×80×8×128×2 B ≈ 0.31 MB，8000 token ≈ 2.5 GB；中文一个字约 1–1.5 token | 用了分组查询注意力的模型；不同模型相差数倍 |
| 过去六到八成页数用不上；分页多服务 2–4 倍 | vLLM（Kwon 等，SOSP 2023）：既有系统 KV 缓存显存利用率仅约 20%–38%，PagedAttention 同等延迟下吞吐提升 2–4 倍 | 画面中的 8 → 3 人、40 页为示意 |
| 连续批处理 | Orca（OSDI 2022）提出迭代级调度：每生成一步就可以换人，而不是等整批结束 | 公交车比喻为示意 |
| 批量通道约 5 折、24 小时内 | OpenAI Batch API、Anthropic Message Batches 均为 50% 折扣、24 小时内返回 | 旁白「常见的是只收一半的钱」，各家以官方为准 |
| 固定说明放最前、命中缓存 | 各家提示词缓存都按「相同前缀」命中，官方建议把不变内容放在最前面 | 命中部分的价格见第 9 期（约 1–5 折） |
| 装模型要几分钟 | 例：70B 模型 16 位权重约 140 GB，从存储载入显存通常需要数分钟 | 量级 |
