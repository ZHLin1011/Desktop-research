## 口播全文

### 1. 同一张图
嗨，我是呱基。门口摄像头拍到这样一幕：一个人把纸箱放在门口，转身走了。有的摄像头会告诉你：检测到人。有的却能说：快递员把包裹放在门口，然后离开了。前一种背后，多半是 CV 小模型；后一种，是视觉大模型。这期聊聊，它们到底差在哪。

### 2. CV 小模型
CV 小模型，是为一件事专门训练的：比如认人和车，或者找产品上的划痕。它把画面一层层看：先找边缘和颜色，再拼成形状，最后认出整体。最后一步像做选择题：选项是训练时就写死的，比如人、车、猫，它给每个选项打分，挑最高的那个。所以它的输出，就是一个框、一个标签、一个分数，比如「人，百分之九十八」。这种模型通常只有几百万个参数，几 MB 大，在摄像头芯片上，每秒能看几十张。

### 3. 视觉大模型
视觉大模型换了一种思路：先把图片切成几百个小方块，每个小方块翻译成一个「视觉词」，和你的问题排在一起，交给一个大语言模型一起读，再一个字一个字写出答案。所以它做的是问答题：你问什么，它就答什么，不用事先定好选项。代价是体量：动辄几十亿个参数，比小模型大上千倍，看一张图常要一两秒。

### 4. 该谁上场
放到生活里，看看该谁上场。流水线上每秒过几十个瓶盖，只查有没有裂纹：小模型又快又稳，一个小盒子就够。出国看不懂菜单，拍一张问哪道不辣：要读字、要理解、还要解释，得靠大模型。小区门口认车牌：格式固定、车流不停、要立刻抬杆，还是小模型的主场。

### 5. 各有短板
小模型的短板是：没教过的，它就不认识。想让它多认一种东西，比如电动车，就得重新收集几千张图，一张张标注，再训练一遍。大模型见多识广，换个问题也能接着答；可它又慢又贵，偶尔还会一本正经地说错，比如把三个人数成四个。

### 6. 搭档
所以现在很多产品，让它们搭档干活。小模型二十四小时站岗，每一帧都过一遍，成本很低；只有发现了人，才把那几张图交给大模型，让它说清楚发生了什么。一天几十万帧画面，真正送去大模型的，可能只有几十张。你收到的，就是一句能看懂的话，而不是一串「检测到人」。

### 7. 收尾
小模型做选择题：选项固定，又快又省；大模型做问答题：什么都能问，但慢一点、贵一点。固定的事交给小模型，说不清的事交给大模型，搭档起来最划算。我是呱基，我们下期见。

## 数字依据（口播取保守、取整表述）

| 说法 | 依据 |
|------|------|
| CV 小模型几百万参数、几 MB | 轻量检测模型如 YOLOv8n 约 320 万参数，FP16 权重约 6 MB；MobileNet 级分类模型 300–500 万参数 |
| 摄像头芯片上每秒几十张 | 轻量检测模型在边缘 NPU 上单帧约 10–30 ms |
| 选项训练时写死 | 分类 / 检测头的类别数在训练时固定（如 COCO 80 类），新增类别需重新标注训练 |
| 先找边缘和颜色，再拼成形状 | 卷积网络浅层响应边缘/颜色，深层组合出部件和物体 |
| 图片切成几百个小方块 | ViT 类视觉编码器按 14–16 像素切块；常见输入每图几百到上千个视觉 token |
| 几十亿参数、大上千倍 | 常见视觉大模型 3B–70B+；3.2M 对 7B 约 2000 倍 |
| 看一张图常要一两秒 | 视觉大模型含图片编码 + 逐字生成，端到端常见 1–数秒 |
| 新增一类要几千张图 | 检测任务新增类别通常需要数千张标注样本 |
| 一天几十万帧 | 按每秒 5 帧做检测：5 × 86400 ≈ 43 万帧 |
