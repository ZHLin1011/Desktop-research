# 第 11 期 · 开发者怎么接入模型（API · Endpoint · API Key · SDK）

- 页面：`dev-api-access.html`（白底，1080×1920，约 273 秒）
- 对象：不是开发者的人。全程用一个比喻——**去餐厅吃饭 vs 自己开店向后厨订货**：API 是点单窗口和规矩，Endpoint 是具体哪一扇窗，API Key 是会员卡，SDK 是现成的下单小程序。
- 结构：先讲清楚「为什么要自己接」（三个好处），再展开四个概念，再把它们串成一条完整调用链，最后给出「自己接一个模型要备齐哪三样、怎么操作」。
- 颜色分工：API 蓝，Endpoint 青，API Key 橙，SDK / 答案绿，模型紫，风险红。

## 分镜

| 场景 | 画面 | 要点 |
|---|---|---|
| 01 从“吃现成”到“开自己的店” | AI 餐厅（点就能吃，老人也会用）→ 并排出现「我的产品」→ 向厂商后厨订货 → 订货的规矩 = API | 成品产品 vs 自己开店；开店要向模型厂商订货 |
| 02 自己接，有三个好处 | 三张卡：微信客服自动答顾客；小模型便宜 / 大模型最强随时换；传送带 5000 件商品文案；按用量收费 | 做进自己的东西、自由挑模型、程序自动批量干活 |
| 03 API：程序用的点单窗口 | 人用界面（输入框、按钮）；程序用窗口 + 规则（怎么点 / 点什么 / 怎么回话）；外卖小程序 → API → 外卖平台 | API 是给程序用的入口 |
| 04 Endpoint：具体哪一扇窗 | 大楼四扇窗（聊天 / 画图 / 语音 / 文字变数字）；网址拆成「整栋楼的门牌」+「哪一扇窗」 | 端点 = 某个功能的网址 |
| 05 API Key：你的会员卡 | 钥匙卡；证明你是谁 + 记在谁的账上；别放公开代码 / 群聊 / 截图；泄露就作废重发，并设额度上限 | 身份 + 计费；保管要点 |
| 06 一次点单，怎么说、怎么回 | 请求单（模型、说什么、旋钮）→ 格式固定 → 回单（答案 + 用量）→ 流式开关 | 请求、响应、按用量计费、流式 |
| 07 SDK：现成的下单工具包 | 手写的五件杂活 vs 几行代码；下单小程序比喻；不用 SDK 也行 | SDK 把杂活打包 |
| 08 一次调用，走了哪些路 | 你的程序 → SDK（拼单、贴 Key）→ 互联网 → Endpoint → 验卡 → 推理服务（第 10 期）→ 答案原路送回 | 完整链路 |
| 09 自己接一个模型，备齐三样 | 地址 / 钥匙 / 模型名三张卡；四步操作；换厂商只改三格，其余代码不动 | 动手清单 |
| 10 四件套，一条链 | 四件套对照；三个价值；钥匙别外泄、用量看账单 | 收束 |

完整逐句旁白在 `dev-api-access.html` 的 `SCENES` 中（TTS 逐词时间戳生成，画面按节拍对齐）。

## 概念与说法依据

| 画面 / 旁白 | 依据 | 备注 |
|---|---|---|
| API = 程序用的入口 | API（Application Programming Interface，应用程序接口）：软件之间约定好的调用方式 | 「点单窗口 + 规则」是比喻 |
| Endpoint = 具体功能的网址 | 一个 API 通常有多个端点（URL），按功能区分，如聊天、图像、语音、向量（embedding） | 画面里的 `api.example.com/v1/chat/completions` 是示例域名，路径参考业界常见的聊天接口命名，各家不同 |
| API Key = 身份 + 计费 + 额度 | 厂商用密钥识别调用方、计费、限流；密钥泄露会被盗刷 | 保管建议：不写进公开仓库、使用环境变量、设置额度上限、泄露立即作废重建 |
| 请求包含模型名、消息、可调参数；响应包含答案和用量 | 主流聊天接口的通用结构：model、messages、temperature / max tokens 等；响应带 token 用量 | 旁白里「字数单位」指 token；用量数字 38 为示意 |
| 流式 | 请求里设置 stream，服务端边生成边返回（见第 10 期） | |
| SDK = 官方工具包 | 厂商提供的 Python / JavaScript 等语言库，封装鉴权、重试、超时、流式解析 | 画面中的代码是示意写法，不对应某一家的真实语法 |
| 换模型往往只改三样 | 不少厂商提供与主流聊天接口兼容的写法（地址、密钥、模型名可替换） | 「往往」；各家细节与可调参数仍可能不同，以官方文档为准 |
| 批量自动干活、按用量收费 | 多数模型 API 按 token 用量计费；批量接口常见约半价（见第 10 期） | |
