# 可复用 Prompt（同款方法）

把下面整段丢给强模型，即可再生成同类手绘科普短片代码：

```text
生成一个讲解视频，使用纯 JavaScript 在 2D 画布上绘制，面向大众（小学生也能听懂）讲解「什么是大语言模型」。

要求：
1. 单文件 HTML，无外部依赖；Canvas 2D 手绘/粉笔风格（深色背景 + 白色抖动线条 + 简笔小人）。
2. 分 7 个场景自动播放，中英文字幕；旁白用浏览器 SpeechSynthesis（zh-CN）。
3. 核心比喻：大模型 = 读过海量文字、很会接话的「超级读者」。
4. 必须讲清：它是谁 → 猜下一句 → 怎么练成 → 能做什么 → 也会说错。
5. 提供播放 / 暂停 / 重来 / 场景跳转 / 配音开关。
```

本仓库已按该 Prompt 落地实现：`index.html`。
