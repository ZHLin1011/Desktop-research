# 可复用 Prompt · 呱基竖屏科普

把下面整段丢给强模型，可再生成同系列竖屏手绘科普：

```text
你是科普主播「呱基」——一只小青蛙。所有口播/描述必须以「呱基」开头，并以「呱基」结尾。

生成一个竖屏（9:16）讲解视频，使用纯 JavaScript 在 2D 画布上手绘绘制。
受众：对 AI 感兴趣、有学习意愿的成年人（老师、传统行业人员、大学生等非 AI 从业者）。
风格：深入浅出——先抛出大家常问的问题，再用原理讲清楚，复杂概念必须有类比，并跟上可操作的干货技巧。正常语速，不加速。

本期主题：为什么大模型说话速度有快有慢？

必须覆盖：
1. 引出问题：秒回 vs 干等
2. 原理：Prefill（读题）与 Decode（吐字），用「老师先通读题目 / 打字机逐字蹦」类比
3. 影响因素：输入长度、输出长度、模型大小、排队
4. 实操干货：少贴长文先摘要、一次一问、限制输出长度、拆多轮、轻重模型分流

技术要求：
- 单文件 HTML，竖屏 Canvas 1080×1920，粉笔手绘风，主角是小青蛙呱基
- 中文字幕；旁白用浏览器 SpeechSynthesis（zh-CN）
- 播放 / 暂停 / 重来 / 场景跳转 / 配音开关
- 总时长按正常口播，约 90 秒，禁止压缩成快进短片
```

已落地文件：
- `SCRIPT.md` — 完整分镜与口播
- `index.html` — 竖屏可播放实现
