# 什么是大模型 · 手绘科普短片

同款方法：用纯 JavaScript 在 2D Canvas 上手绘讲解动画，面向大众通俗介绍「大语言模型是什么」。

## 打开方式

```bash
cd llm-explainer
python3 -m http.server 8765
```

浏览器打开 `http://127.0.0.1:8765`，点「播放」。

## 内容分镜

| 场景 | 一句话 |
|------|--------|
| 开场 | 聊天时对面像超级聪明的朋友 |
| 它是谁 | 大模型 = 读过海量文字的超级读者 |
| 怎么工作 | 不会背答案，而是猜下一句 |
| 怎么练成 | 书 / 网页 / 对话里练功 |
| 能做什么 | 讲故事、答题、翻译、写草稿 |
| 也会说错 | 一本正经也可能错，重要事要核对 |
| 收尾 | 很会接话的超级读者 |

## 技术说明

- 画面：HTML5 Canvas 2D，粉笔手绘抖动笔触
- 旁白：浏览器 `SpeechSynthesis`（中文），无需外部 TTS 密钥
- 单文件：`llm-explainer/index.html`，无构建依赖
